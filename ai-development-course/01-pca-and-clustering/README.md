# Dimensionality Reduction and Clustering Analysis

Работа посвящена обработке многомерных данных, снижению размерности и оценке качества кластеризации.

## Основные этапы:
* **Data Generation:** Создание синтетического набора данных из 3-х визуально разделимых кластеров в 5D пространстве с использованием нелинейных зависимостей ($x_3, x_4, x_5$).
* **Dimensionality Reduction:** Использование метода главных компонент (**PCA**) для сжатия признакового пространства из 5D в 2D.
* **Clustering:** Применение алгоритма кластеризации (K-Means) на сжатых данных.
* **Evaluation:** Анализ оптимальности разделения на 3 кластера.

## Стек:
`Python`, `NumPy`, `Matplotlib`
