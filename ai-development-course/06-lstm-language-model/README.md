# LSTM Language Model

Лабораторная работа №2 по нейросетевым языковым моделям.

Модель использует Word2Vec-эмбеддинги из ЛР1 и обучается предсказывать следующее слово в последовательности.

## Что реализовано

- загрузка словаря и матрицы эмбеддингов из ЛР1;
- очистка и разбиение текстового корпуса;
- подготовка пар `(контекст, целевое слово)`;
- LSTM encoder-decoder модель на TensorFlow/Keras;
- оценка `accuracy` и `perplexity`;
- функция для вывода top-k вариантов следующего слова.

## Стек

Python, NumPy, TensorFlow/Keras, Matplotlib.

## Запуск

1. Подготовить результаты ЛР1: словарь и эмбеддинги Word2Vec.
2. Положить текстовый корпус в папку `data/`.
3. Открыть `lstm_language_model.ipynb` в Colab или Jupyter.
4. Запустить ячейки сверху вниз.

Крупные файлы (`data/`, `embeddings/`, `models/`, `*.keras`) не добавляются в репозиторий.
