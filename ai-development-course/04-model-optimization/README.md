# Model Optimization: Iterative Pruning and Knowledge Distillation

В работе исследуются методы сжатия нейросетей для уменьшения их размера и ускорения работы без потери качества.

## Ключевые методы:
1. **Iterative Pruning:** * Реализовано 5 итераций удаления весов сверточной сети (из ЛР №3).
   * После каждой итерации проводился Fine-tuning (1 эпоха) и финальное дообучение (5 эпох).
2. **Knowledge Distillation:**
   * Процесс "учитель-ученик": перенос знаний из тяжелой CNN в компактную **LSTM**-сеть.
   * Оптимизация размеров LSTM и Dense слоев для сохранения точности исходной модели.

## Результат:
Получена легковесная дистиллированная сеть, показывающая результаты на уровне исходной сверточной архитектуры.
