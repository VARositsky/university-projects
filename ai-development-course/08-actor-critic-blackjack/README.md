# Actor-Critic для Blackjack

Лабораторная работа посвящена реализации алгоритма Actor-Critic для игры Blackjack из библиотеки Gymnasium.

## Цель работы

Цель работы — разработать агента, который обучается играть в Blackjack с использованием policy gradients совместно с value-функцией. В работе используется нейронная сеть-актор для выбора действия и нейронная сеть-критик для оценки состояния.

## Постановка задачи

Среда: `Blackjack-v1`.

Состояние среды задаётся тремя параметрами:

* текущая сумма очков игрока;
* открытая карта дилера;
* наличие usable ace.

Действия агента:

```text
0 — STICK, остановиться
1 — HIT, взять карту
```

Награда:

```text
+1 — победа
 0 — ничья
-1 — поражение
```

## Реализованный алгоритм

В работе реализован алгоритм Actor-Critic.

Актор аппроксимирует policy-функцию:

```text
π(a|s)
```

То есть по текущему состоянию `s` выдаёт вероятности действий.

Критик аппроксимирует value-функцию:

```text
V(s)
```

То есть оценивает, насколько текущее состояние является выгодным для агента.

Обучение проводится по эпизодам. Для каждого эпизода сохраняются состояния, действия и награды. Затем вычисляется дисконтированная сумма наград:

```text
G_t = r_t + gamma * r_{t+1} + gamma^2 * r_{t+2} + ...
```

После этого обновляются обе сети:

* actor loss обучает policy выбирать действия с большим advantage;
* critic loss обучает value-функцию приближать фактическую дисконтированную награду.

## Архитектура модели

Использовались две отдельные нейронные сети.

### Actor

```text
Input: 3
Dense(128, ReLU)
Dense(64, ReLU)
Dense(2, Softmax)
```

### Critic

```text
Input: 3
Dense(128, ReLU)
Dense(64, ReLU)
Dense(1)
```

## Параметры обучения

```text
Количество эпизодов: 500
Learning rate: 0.001
Gamma: 0.99
Epsilon start: 1.0
Epsilon min: 0.05
```

## Предобработка состояния

Состояние нормализуется перед подачей в нейронную сеть:

```python
player_sum / 32.0
dealer_card / 11.0
usable_ace
```

Это позволяет привести входные признаки к близким масштабам и сделать обучение устойчивее.

## Анализ графика value-функции

На графике показана динамика среднего значения `V(s)` по эпизодам. Синяя линия соответствует исходным значениям по эпизодам, красная линия — сглаженному значению с окном 20.

Из-за стохастической природы Blackjack значение `V(s)` заметно колеблется. Это нормально: даже при одинаковой стратегии результат отдельной игры зависит от случайной раздачи карт. Поэтому важнее смотреть не на отдельные пики, а на сглаженную кривую.

В процессе обучения value-функция не сходится монотонно, но постепенно начинает отражать ожидаемую выгодность состояний. Положительные участки соответствуют сериям эпизодов, где критик оценивает состояния как более перспективные, отрицательные — сериям менее удачных состояний и проигрышей.

## Вывод

В результате работы был реализован агент Actor-Critic для Blackjack. Актор отвечает за выбор действия, а критик оценивает состояние через value-функцию. Обученный агент был проверен на серии из 100 игр. По графику value-функции видно, что обучение в Blackjack является шумным и нестабильным по отдельным эпизодам, поэтому для анализа использовалось сглаживание.
