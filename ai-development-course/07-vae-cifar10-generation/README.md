# VAE Image Generation on CIFAR-10

Лабораторная работа посвящена обучению вариационного автоэнкодера на датасете CIFAR-10 и генерации новых изображений через латентное пространство.

## Цель работы

Цель работы — обучить вариационный автоэнкодер, получить средние латентные представления для каждого класса CIFAR-10, сгенерировать новые изображения на основе этих представлений и проверить, насколько сгенерированные данные пригодны для обучения классификатора.

## Что было реализовано

* загрузка и нормализация датасета CIFAR-10;
* построение сверточного энкодера;
* построение декодера на транспонированных сверточных слоях;
* реализация reparameterization trick;
* обучение beta-VAE;
* построение среднего латентного вектора для каждого класса;
* генерация 5000 новых изображений для каждого из 10 классов;
* обучение CNN-классификатора на сгенерированных изображениях;
* проверка классификатора на реальных изображениях CIFAR-10.

## Архитектура VAE

Энкодер принимает изображение размера `32x32x3` и последовательно уменьшает его пространственную размерность с помощью сверточных слоев.

Основные параметры:

* вход: `32x32x3`;
* latent dimension: `128`;
* encoder: `Conv2D 32 -> 64 -> 128 -> 256`;
* decoder: `Conv2DTranspose 128 -> 64 -> 32 -> 3`;
* функция потерь: reconstruction loss + beta * KL divergence;
* beta: `100.0`;
* optimizer: `Adam`;
* learning rate: `0.0005`.

## Генерация изображений

Для каждого класса CIFAR-10 был вычислен средний латентный вектор. Затем к нему добавлялся небольшой нормальный шум:

```python
z_new = z_mean_class + N(0, 0.1)
```

После этого полученные латентные векторы подавались на вход декодеру. В результате было сформировано:

```text
5000 изображений на класс
10 классов
Итого: 50000 сгенерированных изображений
```

## Вывод

Вариационный автоэнкодер позволил построить структурированное латентное пространство и сгенерировать новые изображения для каждого класса CIFAR-10. Однако качество таких изображений ограничено: VAE склонен генерировать размытые объекты, поэтому классификатор, обученный только на синтетических данных, обычно показывает качество ниже, чем CNN, обученная на реальных изображениях.
