# Image Classification on CIFAR-10 with CNN

Реализация и обучение сверточной нейронной сети для классификации изображений 10 классов.

## Архитектура модели:
Модель состоит из 4-х последовательных блоков:
1. **Feature Extraction:** Сверточные слои (`Conv2D`) с увеличением количества фильтров (32 -> 64 -> 128 -> 256).
2. **Regularization:** Использование `BatchNormalization` для стабилизации обучения и `Dropout` для предотвращения переобучения.
3. **Downsampling:** `MaxPooling` для уменьшения размерности признаков.
4. **Classification:** Полносвязный слой (`Dense`) с функцией активации Softmax.

## Результаты:
* **Target Accuracy:** 80 - 85% на тестовой выборке.
* Исследовано влияние гиперпараметров (learning rate, количество эпох) на сходимость модели.

## Стек:
`Python`, `TensorFlow`
